# Metadata Schema

This document describes the schema for `images_metadata.csv`.

## File Format

- **Format:** CSV (Comma-Separated Values)
- **Encoding:** UTF-8
- **Header:** First row contains column names
- **Delimiter:** Comma (`,`)

## Column Definitions

| Column | Type | Required | Description |
|--------|------|----------|-------------|
| `id` | string | Yes | Unique identifier for the image |
| `filename` | string | Yes | Image filename including extension |
| `is_ai` | boolean | Yes | `true` if AI-generated, `false` if real photograph |
| `generator` | string | No | AI model identifier (empty for real images) |
| `category` | string | Yes | Content category of the image |

## Field Details

### `id`

Unique identifier constructed from image properties.

**Format for AI images:**
```
ai_{generator}_{category}_{sequence}
```

**Format for real images:**
```
real_{category}_{source}_{sequence}
```

**Examples:**
- `ai_flux_2_flex_portrait_01`
- `real_landscape_unsplash_042`

### `filename`

The actual filename of the image file.

**Supported formats:**
- `.png` — Lossless format, typically used for AI-generated images
- `.jpg` / `.jpeg` — Compressed format, typically used for real photographs

### `is_ai`

Boolean indicating the ground truth label.

| Value | Meaning |
|-------|---------|
| `true` | Image was generated by an AI model |
| `false` | Image is a real photograph |

### `category`

Content category describing the image subject.

| Value | Description | Examples |
|-------|-------------|----------|
| `portrait` | Human faces, upper body shots | Headshots, selfies, group photos |
| `landscape` | Natural scenery | Mountains, beaches, forests |
| `art` | Artistic styles | Paintings, illustrations, abstract |
| `food` | Food photography | Dishes, ingredients, cooking |
| `animal` | Wildlife and pets | Dogs, cats, birds, wildlife |
| `product` | Commercial items | Electronics, fashion, objects |

## Validation

To validate a metadata file:

```python
import csv

VALID_CATEGORIES = {'portrait', 'landscape', 'art', 'food', 'animal', 'product'}

with open('images_metadata.csv', 'r') as f:
    reader = csv.DictReader(f)
    for row in reader:
        assert row['id'], "Missing id"
        assert row['filename'], "Missing filename"
        assert row['is_ai'] in ('true', 'false'), "Invalid is_ai value"
        assert row['category'] in VALID_CATEGORIES, f"Invalid category: {row['category']}"
        if row['is_ai'] == 'true':
            assert row['generator'], "AI image missing generator"
```
